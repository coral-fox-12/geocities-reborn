    04 The eulogy

    What died, and what came back

    GeoCities hosted 38 million personal homepages and shut down in 2009. The web lost its front yards: pages built by hand, by ordinary people, for no reason except joy. GeoCities Reborn brings them back — the tiled backgrounds, the guestbooks, the visitor counters, the under-construction signs — rebuilt by an AI agent that plans, drafts, and verifies each page like a tiny 1998 webmaster who never sleeps.

    Everything runs locally, with zero dependencies. A generated page is a single HTML file: no tracking, no external images, no server needed. Download it and it works forever, offline, on any machine — the way the old web was supposed to work.

    How it was built: spec-driven with Kiro — see .kiro/specs/geocities-reborn/ for requirements, design, and tasks, and KIRO-USAGE.md for every Kiro session. Kiro CLI 3.3.0 installed in the build environment.
