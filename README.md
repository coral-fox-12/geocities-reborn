# 👻 GeoCities Reborn

**The dead web lives again.** GeoCities hosted 38 million personal homepages
and shut down in 2009. This app brings it back: an AI agent called **Webby**
turns one sentence about you into a complete 1990s personal homepage —
marquee title, tiled background, visitor counter, guestbook, webring,
under-construction badge, and a chiptune — rendered live and downloadable as
a single standalone HTML file.

Built with **Kiro** for **Kiroween 2026** (category: **Resurrection**).

## Try it

```bash
node server.mjs
# open http://127.0.0.1:8931
```

Zero dependencies. No install step, no environment variables, no accounts.
Optional upgrade: set `GROQ_API_KEY` or `GEMINI_API_KEY` (free tiers) and the
agent drafts the bio copy with an LLM; without a key the built-in
deterministic generator runs the whole show and the demo works offline.

## What it does

1. **Type one sentence** — e.g. *"I'm Mimi, a cat who rules the house and
   worships sunbeams"*.
2. **Pick a neighborhood** — Area 51, Hollywood, Sunset Strip, Heartland,
   Enchanted Forest, or Silicon Valley (or let Webby choose).
3. **Watch Webby's plan execute** — parse → theme → draft → render → verify.
4. **Your page appears live** in a retro browser frame: sign the guestbook,
   hear the chiptune, watch the counter tick.
5. **Download it** as a single `.html` file. It works forever, offline, on
   any machine — no server, no tracking, no external images.

## How it was built (Kiro)

Spec-driven with Kiro, exactly the way Kiro wants to be used:

- `.kiro/steering/` — product, tech, and structure steering.
- `.kiro/specs/geocities-reborn/` — `requirements.md` (8 requirements),
  `design.md` (architecture), `tasks.md` (implementation checklist).
- `KIRO-USAGE.md` — every Kiro prompt and session, with evidence.
- Kiro CLI 3.3.0 was installed in the build environment
  (`curl -fsSL https://cli.kiro.dev/install | bash`).
